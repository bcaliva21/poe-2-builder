# Sample questions

Use these to smoke-test the pack after loading a session.

## Build-specific

- For this character, is more crit chance or more shock magnitude the better next investment?
- What support gem would you drop first if I need a socket?
- Am I closer to a shock-magnitude soft wall or a crit-chance soft wall?
- Does this look more hit-scalable or ailment-scalable from the export?

## Generic

- How does shock magnitude stack, and what is the cap?
- When does crit chance stop being worth it relative to crit multi?
- What is the difference between increased damage and increased damage taken?

## Expected agent behavior

- Reads `knowledge/mechanics/` before answering.
- Uses session stats when present.
- Asks for missing numbers instead of inventing them.
- Cites file paths / patch pin.
