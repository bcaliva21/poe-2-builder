# Reference dumps

Optional structured data lives here. The mechanics chapters are enough for many scaling questions; add dumps when answers need exact gem/item/mod text.

## Suggested sources

- [RePoE-fork PoE2](https://repoe-fork.github.io/poe2/) - `base_items`, `mods`, `skills`, `skill_gems`, `uniques`, ...
- [Path of Building Community PoE2](https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2) - hand-maintained unique/rune details
- [GGG poe2 skill tree export](https://github.com/grindinggear/poe2-skilltree-export)

## Conventions

- Prefer slimmed JSON over full dumps (context windows).
- Record patch/version in a sibling `meta.json` when you vendor files.
- Do not commit giant unchanged full dumps unless you need them offline.
